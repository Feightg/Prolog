# Sistema de Consulta de Películas

## Descripción
Este proyecto consiste en el desarrollo de un sistema de consulta de películas utilizando el lenguaje de programación **Prolog**, como parte de la asignatura de Lógica de Programación.

El programa permite consultar información sobre distintas películas mediante hechos y reglas lógicas, aplicando conceptos de programación declarativa.

## Tecnologías utilizadas
- **Lenguaje:** Prolog
- **Entorno de desarrollo:** Visual Studio Code
- **Intérprete:** SWI-Prolog
- **Control de versiones:** Git y GitHub

## Funcionalidades
- Consulta de películas registradas en la base de conocimientos.
- Búsqueda de películas según diferentes características.
- Aplicación de reglas y relaciones lógicas.
- Consultas mediante el intérprete de Prolog.

## Instalación y ejecución

1. Instalar [SWI-Prolog](https://www.swi-prolog.org/).
2. Clonar este repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

3. Abrir la carpeta del proyecto.
4. Ejecutar SWI-Prolog desde la terminal.
5. Cargar el archivo principal:

   ```prolog
   consult('proyectoProlog.pl').
   ```

6. Realizar las consultas disponibles.
